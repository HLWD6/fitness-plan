# 维护说明

当前数据版本为 `fitness-cycle-v15`。升级时将旧版当前训练和历史归档保留，并从今天开始新一轮；首条记录为已完成的卧推5×8、120 kg。后续卧推、深蹲和分腿蹲重量均只记录实际训练数据，不做自动配重。

`src/training.js` 定义16天安排、组次和腿部A/B交替；`src/app.js` 管理本地记录、周期归档及导出；`src/index.html`、`styles.css` 管理页面。

修改源码后运行 `python3 项目资料/scripts/build.py`，更新根目录单文件网页和ZIP。运行 `python3 项目资料/scripts/build.py --check` 检查生成文件。持续集成负责规则检查和网站发布。
