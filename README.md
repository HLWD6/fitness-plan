# 健身计划

固定训练模板与个人日志。8种模板不绑定日期；训练时选择日期和模板，各组实重独立填写，可重复记录和编辑。记录展开为月历，每天直接显示主项实重，没训练的日期留空。

已记入2026年11月9日卧推A、11日深蹲A、12日卧推B、13日引体日（主项未做）、15日卧推C、16日硬拉、18日卧推D、21日卧推A和22日无装深蹲B。15日卧推C按计划五组均为150 kg；16日硬拉五组100 kg，18日卧推D五组8次均为80 kg。11月19日无训练。21日卧推A为5组8次125 kg，22日深蹲B为5组5次120 kg。11日深蹲A五组均为120 kg；12日卧推B五组为120、125、125、130、130 kg。所有模板重量均为参考。

双击[index.html](index.html)可离线使用；[健身计划.zip](健身计划.zip)可分享。[完整模板预览](项目资料/示例/完整计划表.png)。记录保存在当前浏览器，可导出CSV和JSON；旧版数据保留。

源码在`项目资料/src/`。修改后运行`python3 项目资料/scripts/build.py`，再用`--check`核对发布包。项目完成后默认推送Git远端。

电脑上卧推与背腿各一排；平板双列，手机为紧凑单列，动作与组次左右对齐。手机月历整周显示，日期内显示实际重量或重量范围，点选后查看完整逐组记录。深蹲A使用腰带和套膝，参考130 kg。深蹲B完全无装，参考120 kg。两套均为杠铃深蹲5组5次，热身为保加利亚分腿蹲2组，辅助为腿屈伸和腿弯举。硬拉和引体共用高位下拉与器械划船作为辅助。
