# 维护说明

本版使用 `fitness-cycle-v14`：从v13/v12/v11迁移时保留旧进度、训练和归档，并将旧计划存入历史，新技术循环从第1天开始。当前循环16天，卧推方式依次为容量、控制稳定、赛推专项、减载。无上版数据时，卧推参考极限160 kg、深蹲120 kg。

`src/training.js` 定义四种卧推重量、四天训练节奏和周期长度。`src/app.js` 管理设置、记录、归档及循环重开；新循环需要至少5个完整休息日。`src/index.html`、`styles.css` 和 `mobile.js` 管理界面。修改源码或文档后运行 `python3 项目资料/scripts/build.py` 更新单文件网页及ZIP；`--check`只校验生成结果。持续集成负责规则测试与发布文件检查。

卧推参考重量仅为起始估算，RPE需根据实际表现校准。
