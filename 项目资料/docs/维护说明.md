# 项目维护说明

当前版本：v10（2026-10-30）。唯一维护目录为 `/home/k405/Desktop/fitness-plan`。只有用户明确要求时才推送远端或发布网站。

## 架构

- `src/index.html`、`styles.css`：精简的响应式单页界面，浅蓝绿配色，手机和桌面共用内容，字号至少16px。
- `src/training.js`：纯计算，包括三层周期、四个独立卧推起点、腿A/B、日期顺延及测试日期；Node与浏览器共用。
- `src/app.js`：设置、计划卡片、记录、草稿、归档、旧数据只读展示、CSV/JSON导出及打印。
- `src/mobile.js`：手机导航高亮；`scripts/build.py`：生成内嵌全部资源的根目录HTML和ZIP。
- `tests/`：训练规则、桌面记录流程和手机界面测试。

## 本轮语义

默认2026-10-30从第9天开始记录，当前是第三次卧推137.5 kg 6×5。第1轮四种卧推分别为122.5/130/137.5/145 kg，后续每轮四项各加5 kg；四个起点独立可编辑，修改1RM不应自动覆盖起点。可主动按70/75/80/85%生成参考；结束周期测试后，新周期先以新1RM生成可修改参考值。

此前日期只作倒推参考，早于开始记录日的训练不自动算作完成、也不生成记录。默认下一次深蹲120 kg，随后每个腿日加5 kg；较早腿日未录入重量不得推测。腿A/B继续依照第1轮的四天节奏交替。用户可在设置中指定下一次深蹲重量作为后续锚点。

实际训练晚于计划则后续日期顺延；休息日无需打卡；暂停会记入尝试但不推进。已完成记录保存当时处方。最后一个正常休息日后再休息至少5个完整日，才允许记录1RM测试。

本版使用 `fitness-cycle-v10`，旧 `fitness-cycle-v9`、`bench-rotation-v8` 及更早版本键不覆盖、不删除；可只读展示并一并导出JSON。新周期不自动导入旧进度，避免把旧安排误当作本轮训练。不得清理用户浏览器历史。JSON当前只导出，不提供导入界面。
