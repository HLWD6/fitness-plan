## 当天怎么练

- **胸**：轻量温宁式热身 → 卧推 → 实力推 → 三头任选一项＋哑铃弯举 → 平板支撑或卷腹。
- **背**：引体向上 → 高位下拉＋器械划船。
- **腿A**：深蹲 → 哈克深蹲 → 腿屈伸＋腿弯举。
- **腿B**：深蹲 → 硬拉，不做二级辅助。腿A、B交替。

辅助组次是初始建议，以动作稳定、留有余力为准。卧推使用保护；疼痛、动作失控或明显疲劳时暂停。未完成不会自动降重，不要强行加重；请调整设置或多休息。

## 记录与调整

1. 设置里可修改1RM、四个卧推重量、加重幅度、开始日期和天数。第9天对应的开始日期默认是2026年10月30日。
2. 点击计划格子可预览。按顺序记录训练；休息日无需打卡。训练晚于计划时，之后日期自动顺延。
3. 实际重量、次数与备注可选填；也可标记未完成或暂停。暂停会留下记录，但不会推进训练。
4. 需要改变下次深蹲时，可在设置中单独填写下次重量，此后从该重量继续递增。已记录处方不变。
5. 完成所选轮数后，最后一个正常休息日之后再休至少5个完整日；状态恢复后测试卧推1RM，再建立新周期。新周期按新1RM生成四个参考重量，可在设置中修改。

记录不会跨设备或网址自动同步。“导出全部记录”包括本版及当前浏览器可访问的旧版数据；当前不提供导入界面。旧版记录在记录区只读保留。CSV是当前计划表，不是恢复备份。
