# 维护说明

当前数据版本为 `fitness-cycle-v15`。页面显示卧推近似参考重量，但保存的实际训练记录独立保留；更新参考值不会覆盖用户的实重记录。初始记录为卧推5×8、120 kg。

首页用4×4日历呈现16天动作与组次，手机为双列；点击日期打开记录弹窗，完成记录用淡绿色背景标记，下一次训练用淡蓝色标记。`src/training.js` 定义16天安排、组次和腿部A/B交替；`src/app.js` 管理日历、记录弹窗、周期归档及导出；`src/index.html`、`styles.css` 管理页面结构和布局。

修改源码后运行 `python3 项目资料/scripts/build.py`，更新根目录单文件网页和ZIP。运行 `python3 项目资料/scripts/build.py --check` 检查生成文件。持续集成负责规则检查和网站发布。
