# 健身计划

固定训练模板与个人日志。7种模板不绑定日期；训练时选择日期和模板，各组实重独立填写，可重复记录和编辑。休息可记录，不占模板板。

已记入2026年11月9日卧推A、10日休息、11日深蹲A、12日卧推B。12日卧推B五组为120、125、125、130、130 kg。所有模板重量均为参考。

双击[index.html](index.html)可离线使用；[健身计划.zip](健身计划.zip)可分享。[完整模板预览](项目资料/示例/完整计划表.png)。记录保存在当前浏览器，可导出CSV和JSON；旧版数据保留。

源码在`项目资料/src/`。修改后运行`python3 项目资料/scripts/build.py`，再用`--check`核对发布包。项目完成后默认推送Git远端。
