# 维护说明

本版使用 `fitness-cycle-v13`：首次打开时从v12或v11迁移进度、记录和归档，保留历史处方，并将两轮基准设为160/170 kg，按新组次重算未记录的卧推重量。旧键不会覆盖，旧版数据仍可查看和导出。无上版数据时从第1天开始，深蹲120 kg、增量0。

`src/training.js` 定义卧推组次、RPE目标估算和四天训练节奏。`src/app.js` 管理设置、记录、归档及新周期；周期增量只在开启新周期时应用。`src/index.html`、`styles.css` 和 `mobile.js` 管理界面。修改源码或文档后运行 `python3 项目资料/scripts/build.py` 更新单文件网页及ZIP；`--check`只校验生成结果。持续集成会运行训练规则测试并检查构建产物。

训练重量按经验模型估算，不代表实际RPE已测得；如要调整，优先依据训练记录中的实际表现和RPE。
