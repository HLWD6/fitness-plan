# 健身计划 · 使用说明

胸、背、腿、休息四天一组。四种卧推各做一次，16天完成一个循环；卧推日之间间隔4天。

| 卧推日 | 动作安排 | 默认重量（参考极限160 kg） |
|---|---|---:|
| 容量日 | 快速卧推 5×8 | 110 kg |
| 控制稳定日 | 胸前停顿、不反弹 5×5 | 120 kg |
| 赛推专项日 | 比赛式卧推，练腿驱动、陷胸承接和推起路线 5×3 | 130 kg |
| 减载日 | 无腿驱动卧推 5×8 | 87.5 kg |

重量分别按参考极限的70%、75%、82.5%和55%计算，再按杠铃最小档距向下取整。前三种动作以末组 RPE 7–8 为起点估算，减载日约 RPE 6；实际强度会因动作方式和当天状态不同而改变。疼痛、动作变形或负重明显过重时，减重或停止。

背日安排引体向上、高位下拉和器械划船。腿日深蹲5×5，腿A为哈克深蹲、腿屈伸和腿弯举；腿B为硬拉，不做二级辅助。深蹲默认120 kg。减载卧推日不安排大重量辅助。

完成一个循环后，休息至少5个完整日，再按复测结果开启下一循环。默认卧推参考极限加2.5 kg，可在设置中调整；最小加重默认2.5 kg。

升级到本版会把旧计划和训练记录归档保留，新循环从第1天开始。记录保存在当前浏览器；换设备前请导出JSON。
