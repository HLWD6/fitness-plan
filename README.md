# 健身计划

个人训练计划网页：胸、背、腿、休息四天一组；卧推两轮各五次，共十次训练。输入 eTM 自动计算重量，完成十次后可评估加重。

双击 [index.html](index.html) 可离线使用；[健身计划.zip](健身计划.zip) 可分享。训练记录保存在浏览器；旧版记录可查看及导出。

源码在 `项目资料/src/`，详细安排见 [训练计划与依据](项目资料/docs/重建计划与研究依据.md)。修改后运行 `node --test 项目资料/tests/training.test.cjs`、`python3 项目资料/scripts/build.py` 和 `python3 项目资料/scripts/build.py --check`。仅在用户要求时上传远端。
