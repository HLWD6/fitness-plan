# 健身计划

个人训练记录网页：胸、背、腿、休息四天一组；卧推容量、控制、赛推、减载四种方式依次轮换，16天完成一轮。重量不自动推算，训练后记录实重；腿部轮换杠铃深蹲与保加利亚分腿蹲。

双击 [index.html](index.html) 可离线使用；[健身计划.zip](健身计划.zip) 可分享。首条训练记录为卧推5×8、120 kg。训练记录保存在浏览器；旧版记录可查看及导出。

源码在 `项目资料/src/`，详细安排见 [训练计划](项目资料/docs/重建计划与研究依据.md)。修改后运行 `python3 项目资料/scripts/build.py` 更新页面，再运行 `python3 项目资料/scripts/build.py --check` 检查。项目完成后默认推送 Git 远端。
