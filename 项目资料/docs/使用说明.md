# 健身计划 · 使用说明

## 训练节奏

胸、背、腿、休息四天一组，16天完成一轮。

打开网页先看到完整计划表，包含每天的主项和辅助动作。淡绿色表示已完成，淡蓝色表示下一次训练；点某一天的“记录”可填写实际训练。

| 训练日 | 安排 |
|---|---|
| 卧推容量日 | 快速卧推 5×8；参考约 120 kg |
| 卧推控制日 | 胸前停顿、不弹胸 5×5；参考约 135 kg |
| 卧推专项日 | 比赛式卧推，练腿驱动与技术 5×3；参考约 150 kg |
| 卧推减载日 | 无腿驱动卧推 5×8；参考约 100 kg |
| 背日 | 引体向上、高位下拉、器械划船 |
| 腿日 A | 杠铃深蹲 5×5、哈克深蹲、腿屈伸和腿弯举 |
| 腿日 B | 保加利亚分腿蹲 3×8–10/腿 |

腿日A与B每次交替。卧推参考值只作起点，不自动递增；按当天状态选择实际重量，训练后在记录卡另行填写。腿部负重也由本人选择和记录。哑铃保加利亚分腿蹲填写每只哑铃的重量，其他训练表现可写在表现记录中。

当前首条记录为快速卧推 5×8、120 kg。进度、训练记录和周期归档保存在当前浏览器；换设备前请导出JSON备份。CSV可用于整理训练数据。

完成16天训练后，休息至少5个完整日，再复测并开启新周期。新周期会归档上一轮。
