# 维护说明

本版使用 `fitness-cycle-v12`：首次打开时从 `fitness-cycle-v11` 保留进度、记录、归档和历史处方，eTM改为160并按新表重算未来重量；旧键不覆盖，记录页及JSON仍可查看导出。无上版数据时从第1天开始，深蹲120 kg、增量0。

`src/training.js` 定义两轮各5次卧推、四天胸背腿休及按 eTM 配片。`src/app.js` 管理设置、记录、归档及手动开启下一周期；周期增量只在开启下一周期时应用。`src/index.html`、`styles.css` 和 `mobile.js` 是界面。修改源码或文档后运行 `python3 项目资料/scripts/build.py`，再运行 `--check`。`node --test 项目资料/tests/training.test.cjs` 检查规则；浏览器测试使用项目外的Playwright和独立临时上下文。

只有用户明确要求时才推送远端；绝不删除个人浏览器记录。
