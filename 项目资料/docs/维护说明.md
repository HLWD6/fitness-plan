# 维护说明

数据版本为`fitness-templates-v17`。`src/training.js`集中定义7种训练模板及月历计算、已确认历史、逐组实重校验和记录更新；`src/app.js`负责模板板、记录弹窗、编辑、迁移和导出。日期属于训练记录，模板不安排日期和训练先后。

首次进入v17时，从v16迁入训练日志，去掉休息项，并一次性将2026年11月11日深蹲A补为五组120 kg。原始v16保留在原存储键和JSON备份中。没有v16时迁入v15其他日期日志，并预置11月9日、11日和12日三次训练。旧版单一实重以`legacyWeight`保留，不推断逐组重量。后续刷新使用已保存的v17数据，不重复初始化或覆盖用户编辑。

模板参考值与每条日志的`setWeights`独立。空重量为`null`，不套用参考重量；同一模板跨日期可重复使用，同日期同模板更新原记录。每条日志保存模板快照。原始旧版记录可在旧记录区查看，也随JSON导出。

模板标题25–28px，正文15–18px，次要文字至少14px；手机窄屏允许单列，不用缩小文字强塞内容。界面采用浅蓝绿底、独立圆角模板卡、深色主项和组次标签。四种卧推与背腿模板分别排布；手机双列卧推、单列背腿。记录展开为按周一对齐的月历；空白日期不生成休息记录，每个日期直接展示主项实重，点击可查看详细组次和编辑。手机月历保持大字号，可横向滚动查看整周。

修改后运行`python3 项目资料/scripts/build.py`生成单文件网页与ZIP，`--check`核对发布文件。测试位于`tests/`，预览与导出示例位于`示例/`。完成后默认推送Git。

模板处方由`prescription()`统一格式化为组数、次数、重量；未知重量不推算。`actualWeightSummary()`只读取日志实重，用于日历显示，不读取模板参考重量。历史快照继续保留原训练组次；模板更新不会改写旧日志。三头动作已固定，不再显示任选字段。
