# 健身计划 · 使用说明

## 训练节奏

胸、背、腿、休息四天一组，16天完成一轮。

| 训练日 | 安排 |
|---|---|
| 卧推容量日 | 快速卧推 5×8 |
| 卧推控制日 | 胸前停顿、不弹胸 5×5 |
| 卧推专项日 | 比赛式卧推，练腿驱动与技术 5×3 |
| 卧推减载日 | 无腿驱动卧推 5×8 |
| 背日 | 引体向上、高位下拉、器械划船 |
| 腿日 A | 杠铃深蹲 5×5、哈克深蹲、腿屈伸和腿弯举 |
| 腿日 B | 保加利亚分腿蹲 3×8–10/腿 |

腿日A与B每次交替。卧推和腿部训练重量均由本人按当天状态选择，不自动推算；完成训练后在记录卡填写实际主项重量。哑铃保加利亚分腿蹲填写每只哑铃的重量，其他训练表现可写在表现记录中。

当前首条记录为快速卧推 5×8、120 kg。进度、训练记录和周期归档保存在当前浏览器；换设备前请导出JSON备份。CSV可用于整理训练数据。

完成16天训练后，休息至少5个完整日，再复测并开启新周期。新周期会归档上一轮。
