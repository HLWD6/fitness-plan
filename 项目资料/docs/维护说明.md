# 维护说明

数据版本为`fitness-templates-v16`。`src/training.js`集中定义7种训练模板及休息选项、已确认历史、逐组实重校验和记录更新；`src/app.js`负责模板板、记录弹窗、编辑、迁移和导出。日期属于训练记录，模板不安排日期和训练先后。

首次进入v16时，录入用户确认的2026年11月9日至12日四条记录；v15这些日期的旧数据保留在原存储键，其他日期的现有记录迁入新日志。旧版单一实重以`legacyWeight`保留，不推断逐组重量。后续刷新使用已保存的v16数据，不重复初始化或覆盖用户编辑。

模板参考值与每条日志的`setWeights`独立。空重量为`null`，不套用参考重量；同一模板跨日期可重复使用，同日期同模板更新原记录。每条日志保存模板快照。原始旧版记录可在旧记录区查看，也随JSON导出。

界面采用浅蓝绿底、独立圆角模板卡、深色主项和组次标签。四种卧推与背腿模板分别排布；手机双列卧推、单列背腿。休息只出现在记录选择器与历史中。

修改后运行`python3 项目资料/scripts/build.py`生成单文件网页与ZIP，`--check`核对发布文件。测试位于`tests/`，预览与导出示例位于`示例/`。完成后默认推送Git。
