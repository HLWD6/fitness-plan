## 每次训练

| 日 | 主项及辅助 |
|---|---|
| 胸 | 温宁式轻热身；卧推；一级实力推2×6–8；二级三头任选一项＋哑铃弯举各2×10–15；三级平板支撑2×20–40秒或卷腹2×10–20 |
| 背 | 引体向上3×5–8；高位下拉及器械划船各2×8–12 |
| 腿A | 深蹲5×5；哈克深蹲2×8–12；腿屈伸和腿弯举各2×10–15 |
| 腿B | 深蹲5×5；硬拉2×5；不做二级辅助 |
| 休息 | 散步或轻活动，按恢复情况顺延 |

胸日热身沿用此前要求的六项、两轮、每项25次：侧平板、卷腹、轻夹胸推、胸托后束飞鸟、轻臂屈伸、轻面拉；单侧动作两轮各一侧。全部保持很轻松，出现疲劳就减少。随后单独做逐渐加重的专项准备。三头可选自重、直杆、绳索或过顶臂屈伸。辅助组次是初始建议，可按恢复调整。

## 执行原则与参考

卧推和深蹲使用安全杆或可靠保护。第三轮卧推155 kg 8×3约为当前1RM的92.5%，是高强度目标；所有自动排出的重量都不是完成保证。疼痛、动作失控、未完成或明显累积疲劳时暂停，先恢复并调整重量。系统不会自动降重；测试1RM需要充分恢复和保护。

组次和当前重量是用户指定的个人安排，不是原版 Smolov。需要生成参考起点时，网页使用 [Smolov 基础周期公开安排](https://www.smolovjr.com/smolov-squat-routine/)的70/75/80/85%作为可修改参考。热身借鉴 [Wenning Strength 公开示例](https://wenningstrength.com/wp-content/uploads/Conjugate-Training-on-a-Budget_SAMPLEWEEK-1.pdf) 的轻负荷准备思路，六项两轮是本计划选择。避免反复练到力竭有助于控制疲劳，见 [Morán-Navarro 等的恢复研究](https://pubmed.ncbi.nlm.nih.gov/28965198/)；研究不能证明本计划或固定加重最适合个人。
