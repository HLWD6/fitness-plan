# 训练模板

模板用于记录，不绑定日期或自动递增重量。

| 模板 | 主项 | 参考重量 |
|---|---|---|
| 卧推A · 容量 | 快速卧推5×8 | 120 kg |
| 卧推B · 控制 | 停顿卧推5×5 | 135 kg |
| 卧推C · 赛推 | 赛推5×3 | 150 kg |
| 卧推D · 减载 | 无腿卧推5×8 | 100 kg |
| 背部 | 引体向上3×5–8 | 自定 |
| 深蹲A | 杠铃深蹲5×5 | 自定 |
| 深蹲B | 保加利亚分腿蹲3×8–10/腿 | 自重或哑铃 |

卧推一级辅助分别为实力推2组、自重臂屈伸4组、俯卧撑2组，减载无辅助。卧推A/B/C加三头5×10–15、哑铃弯举1×12（参考22.5 kg）、平板支撑或卷腹2组。

背部加高位下拉、器械划船各2×8–12；深蹲A加哈克深蹲2×8–12、腿屈伸和腿弯举各2×10–15；深蹲B不加辅助。

每次记录自选日期、模板和实际重量。模板参考值不会覆盖实重，各组可用不同重量。2026年11月12日卧推B已记为120、125、125、130、130 kg，模板仍参考135 kg。
