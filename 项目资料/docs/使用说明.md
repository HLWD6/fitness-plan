# 健身计划 · 使用说明

胸、背、腿、休息四天一组。每轮20天、五次卧推；两轮共40天、十次卧推。

设置中分别填写第一轮和第二轮的估算极限，默认160 kg和170 kg。卧推处方按每轮基准、组次和组数估算，以末组 RPE 7–8 为目标；重量向下配到器械最小档距。默认档距2.5 kg。RPE只是估计，若末组超过8、动作变形或速度明显下降，减重2.5–5 kg或结束该项。

每轮卧推组次：

- 第一轮：4×10、5×8、6×6、8×4、10×2。
- 第二轮：4×9、5×7、6×5、8×3、15×1。

每完成两轮并确认恢复后，可开启新周期。默认两轮估算极限各加5 kg，也可以按复测结果分别设置。辅助动作和腿日安排见计划表。

数据保存在当前浏览器。升级到本版会保留上一版进度、训练记录和归档；已保存的历史处方不变，尚未记录的训练按新组次与重量重新计算。换设备前请导出完整JSON；当前不支持导入。
