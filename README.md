# 力量训练计划

可离线使用的个人训练计划与记录网页，手机、平板和电脑共用。当前按“胸 → 背 → 腿 → 休息”循环，16天一轮；本轮已进行到2026年10月30日的第9天、第三次卧推。

- 打开：[index.html](index.html)；分享可发送 [健身计划.zip](健身计划.zip)。
- 本轮卧推：122.5、130、137.5、145 kg；后续每个16天循环，四项各加5 kg。
- 1RM、四个卧推起点、杠铃档距、增重、训练开始日期与天数均可修改。此前未录入的训练不会自动算作已完成。
- 记录只保存在当前浏览器；可导出包含旧版记录的完整JSON。
- 说明：[使用说明](项目资料/docs/使用说明.md) · [训练计划与依据](项目资料/docs/重建计划与研究依据.md) · [维护说明](项目资料/docs/维护说明.md)

## 维护

源码位于 `项目资料/src/`，不要只编辑生成的根目录HTML。修改后执行：

```bash
node --check 项目资料/src/training.js
node --check 项目资料/src/app.js
node --check 项目资料/src/mobile.js
node --test 项目资料/tests/training.test.cjs
python3 项目资料/scripts/build.py
python3 项目资料/scripts/build.py --check
```

浏览器回归测试见维护说明。构建只需要Python标准库；生成的网页和ZIP可离线使用。只有用户明确要求上传或发布时，才向远端推送。线上网页与本地文件不会自动同步训练记录。
