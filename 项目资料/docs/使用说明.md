# 健身计划 · 使用说明

胸、背、腿、休息四天一组。五次卧推为一轮，第一轮 5×10、8、6、4、2；第二轮 5×9、7、5、3、1。两轮共十次卧推，正常安排40天。

设置里填写卧推 eTM（默认165 kg）、杠铃杆重及最小总增量，保存后自动计算重量。十次卧推完成后，状态恢复允许时可开启下一周期，默认每项加5 kg；不适合加重时先把增量调低。5×1接近极限，使用保护，出现疲劳或动作不稳应降重或结束。

一级辅助依次为实力推、上斜卧推、自重臂屈伸、俯卧撑、器械卧推，两轮相同。二级辅助为三头任选一项和哑铃弯举。背和腿继续原有安排。

数据保存在当前浏览器。新计划独立开始，旧版记录保留在原处，可在记录页查看和导出。换设备前导出完整JSON；当前不支持导入。
